# GUO YUSHENG DIGITAL EXPERIENCE

# DESIGN_SYSTEM.md v1.1

## 1. Design Philosophy

This project is an immersive WebGL digital exhibition space.

It is not a traditional portfolio website.

The website itself is the first demonstration of technical ability.

The experience should communicate:

-   Creative frontend engineering
-   WebGL capability
-   Motion design
-   AI exploration
-   Digital product thinking

Core principle:

> Technology becomes visual experience.

------------------------------------------------------------------------

# 2. Visual Direction

## Keywords

-   Experimental
-   Premium technology

Avoid:

A futuristic digital laboratory.

# 5. Depth Philosophy

The website is not a vertical page.

Scrolling represents spatial exploration.

The user moves deeper into a digital world.

Experience layers:

    Surface
       ↓
    Identity
       ↓
    Archive
       ↓
    Technology
       ↓
    Core

Each layer represents deeper understanding of the creator.

The user should feel:

Entering a system.

Not browsing a website.

------------------------------------------------------------------------

# 6. Core Object System

## G Core

The G is the central digital object.

It is not simply a logo.

It represents:

-   Identity
-   Creativity
-   Technology core

Visual characteristics:

-   Transparent
-   Metallic
-   Glass-like
-   Heavy
-   Precise

Material feeling:

-   Crystal
-   Optical glass
-   Liquid metal
-   Holographic object

The G Core should always feel like a physical object existing in 3D
space.

------------------------------------------------------------------------

# 7. Environment System

The world is a futuristic laboratory.

Environment:

-   Infinite grid
-   Deep space
-   Atmospheric fog
-   Particles
-   Volumetric lighting

The environment should have depth.

The viewer should feel there is an endless space behind the screen.

------------------------------------------------------------------------

# 8. Camera Philosophy

Camera movement represents exploration.

Not page scrolling.

Movement rules:

-   Smooth
-   Cinematic
-   Slow acceleration
-   Physical feeling

Avoid:

-   Fast gaming camera
-   Sudden jumps
-   Artificial movement

------------------------------------------------------------------------

# 9. Scene Architecture

## Scene 01 --- Identity Core

Purpose:

Create the first impression.

Sequence:

1.  Black screen
2.  Digital laboratory initializes
3.  Grid appears
4.  G Core is constructed
5.  Scanner light passes through
6.  Surface noise appears
7.  G breaks into particles
8.  Particles reconstruct
9.  GUO YUSHENG appears
10. Transparent G rotates around identity

Feeling:

System activation.

------------------------------------------------------------------------

## Scene 02 --- Project Archive

Transition:

The G Core breaks apart.

Particles fall into a deep digital abyss.

The camera follows downward.

A new world emerges.

Projects are:

Digital artifacts.

Not cards.

Display rules:

-   Do not show everything immediately
-   Keep unknown objects hidden
-   Use blur and depth
-   Reveal through interaction

Interaction:

Mouse movement controls:

-   Camera rotation
-   Object rotation
-   Project orbit

When a project reaches the front:

The project becomes the main focus.

It can cover the G Core.

The project has visual priority.

------------------------------------------------------------------------

## Scene 03 --- Technology Matrix

Technology should become a spatial system.

Avoid:

    React 90%
    GSAP 85%

Instead:

Nodes:

-   React
-   GSAP
-   Three.js
-   WebGL
-   Remotion
-   AI Tools

Connected around the G Core.

------------------------------------------------------------------------

## Scene 04 --- Final Message

After the complex dark world:

Transition into a clean minimal space.

Background rises from below.

The experience becomes calm.

Message:

    I build digital experiences
    where technology meets imagination.

------------------------------------------------------------------------
